# Host-Microbiota Multi-Omics

MSc course at the University of Copenhagen on the joint analysis of host and microbiota data using multi-omics approaches.

**Course website and practicals:** [host-microbiota-multi-omics.github.io](https://host-microbiota-multi-omics.github.io)

## About the course

The course introduces the computational workflows used to generate and integrate multi-omic data from hosts and their associated microbiomes. The practicals are delivered as a webbook with step-by-step instructions, code snippets and explanations.

## Topics

- **Computation basics:** getting ready, command line basics, high-performance computing (HPC/SLURM) and Snakemake
- **Data processing:** preprocessing of sequencing data
- **Host genome:** analysis of host genomic data
- **Microbial metagenome:** analysis of microbial metagenomic data
- **Data integration:** combining omic layers
